# Прыгающий слон — Jetpack Compose + Lottie

![preview](docs/elephant_jump.gif)

Android-приложение на Jetpack Compose: на экране слон (Lottie-анимация `app/src/main/res/raw/elephant.json`).
В покое слон дышит, шевелит ушами, хоботом и хвостом. **По нажатию на слона он прыгает.**

## Фазы прыжка

| Кадры (60 fps) | Фаза | Что происходит |
|---|---|---|
| 0–22 | Подготовка | слон приседает, колени сгибаются, голова прижимается к плечам, хобот подворачивается, уши прижаты |
| 22–30 | Толчок | лапы распрямляются с ускорением, тело вытягивается (stretch) |
| 30–53 | Взлёт | баллистика `h = v0·t − g·t²/2`, лапы поджимаются под живот, хвост и уши по инерции отстают |
| 53–76 | Падение с верхней точки | голова вытягивается вперёд-вверх, хобот поднимается, лапы тянутся к земле |
| 76–140 | Приземление | затухающая пружина: тело проседает (squash), колени сгибаются, голова и уши по инерции «клюют» вниз, затем всё успокаивается |
| 140–260 | Idle (цикл) | дыхание, взмахи ушами, покачивание хвоста |

## Как устроена анимация

Анимация сгенерирована скриптом [`tools/generate_elephant.py`](tools/generate_elephant.py) (Python 3, без зависимостей):

* слон — это риг из слоёв с родителями: `тело → голова → уши / хобот (3 сегмента)`,
  `тело → бедро → голень → стопа` (×4 лапы), `тело → хвост (2 сегмента)`;
* высота тела считается по физике (присед, толчок, полёт с гравитацией, приземление — затухающая пружина);
* лапы решаются двухзвенной **инверсной кинематикой**: стопы стоят на земле, пока тело приседает,
  поэтому колени реально сгибаются; в полёте стопы поджимаются;
* голова, уши, хобот, хвост и наклон тела — затухающие пружины, которые следуют за целевой позой фазы
  и дополнительно раскачиваются вертикальным ускорением тела (инерция);
* в JSON есть маркеры `jump` и `idle`, которые использует приложение (`LottieClipSpec.Marker`).

Чтобы поменять анимацию (высоту прыжка, тайминги, цвета) — отредактируйте константы в скрипте и запустите:

```bash
python3 tools/generate_elephant.py
```

## Сборка

Откройте проект в Android Studio (Ladybug или новее) или:

```bash
./gradlew :app:assembleDebug
```

Стек: Kotlin 2.0, AGP 8.7, Compose BOM 2024.12, `com.airbnb.android:lottie-compose:6.6.2`, minSdk 24.
